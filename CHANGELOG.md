# Changelog

## 0.5.0

Covers 95 of 97 operations in the public API contract. The two remaining operations are provider callbacks.

### Added

- Meetings: list and inspect captured events, update their targets, retry captures, sync the calendar, and write results back to it.
- Protocols: generate custom protocols, list, edit, approve, and export saved protocols, and manage templates.
- Recordings and CRM: list tags and folders, update recording metadata, and queue, inspect, or retry CRM deliveries.
- Integrations: list, create, and remove connections and request provider OAuth authorization URLs.
- Webhooks: read and rotate the signing secret.
- Billing: request a card balance top-up.
